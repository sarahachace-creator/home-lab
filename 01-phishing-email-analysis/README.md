# Phishing Email Analysis

## Overview

This project documents my investigation of a simulated phishing email from the perspective of a SOC analyst. The goal of this lab is to practice identifying phishing indicators, analyzing email headers, examining email authentication results, extracting indicators of compromise (IOCs), and documenting the investigation.

## Objectives

- Analyze a suspicious email and its headers
- Identify sender and domain inconsistencies
- Understand SPF, DKIM, and DMARC authentication
- Identify suspicious URLs and other indicators
- Extract and documents IOCs
- Map relevant activity to the MITRE ATT&CK framework
- Create a SOC-style incident report
